# Capturas de tela

Geradas por `frontend/scripts/screenshots.mjs` a partir do **modo
demonstração**, cujo dataset é sintético e determinístico. Todos os nomes,
vagas e decisões nas imagens são fictícios.

Para regenerar:

```bash
cd frontend
npm run build
npm run preview &
npm run screenshots
```
